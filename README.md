# Aurora Todo

A simple Todo app built with:

- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage

## Features

- Add tasks
- Edit tasks
- Complete/uncomplete tasks
- Delete tasks
- Filter All / Active / Completed
- Clear completed tasks
- Task counter
- Animated Aurora Glass background
- Responsive design
- Automatically saves tasks in LocalStorage

## Run

No build step is required.

Open `index.html` in a browser, or use VS Code Live Server.

## Data

Tasks are stored locally in the browser under:

`aurora-todo-tasks`

No account, backend, database, or API is required.
